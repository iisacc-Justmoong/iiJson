# 네이티브 숫자 출력

부동소수점 출력은 iiSDKCore의 로케일 독립 왕복 변환을 사용한다. macOS 12 지원을 위해 13.3부터 제공되는 libc++의 부동소수점 `to_chars`를 요구하지 않는다. 정수 출력은 기존 정수 `to_chars`를 사용한다.

Double 값에는 필요한 경우 `.0`을 붙여 JSON을 다시 읽을 때 정수 변형으로 바뀌지 않게 한다. NaN·무한대·언더플로·잘못된 JSON 숫자 거부는 기존 계약 검사를 유지한다. `iiJson.Contracts`와 Core의 비트 패턴 왕복 검사를 함께 수행한다.
